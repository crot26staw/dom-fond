# Дом-фонд

Контекст проекта для следующих сессий. Сверено с данными Figma REST API 21 ноября 2026 года. Перед вёрсткой конкретного блока открывай его актуальный фрейм и сверяй размеры, переносы и состояния по макету.

## Проект и команды

- Актуальная рабочая папка проекта — `/Users/user/Desktop/Дом-фонд` (`~/Desktop/Дом-фонд`). Если сессия Codex указывает на прежний путь `/Users/user/Documents/ChatGPT/Дом-фонд`, запускай команды в папке на рабочем столе.
- Благотворительный фонд «ДОМ». Вёрстка на HTML, CSS и JavaScript, сборка Vite, анимация GSAP/ScrollTrigger, плавная прокрутка Lenis. Готовую страницу планируется перенести в WordPress.
- На момент анализа есть только стартовый экран с заголовком. Разметка в `index.html`, стили в `src/styles.css`, подключение Lenis и ScrollTrigger в `src/main.js`. Инициализация привязана к `[data-landing]` и учитывает `prefers-reduced-motion`.
- `npm ci` устанавливает зависимости по локфайлу. `npm run dev` запускает разработку, `npm run build` собирает `dist/`, `npm run preview` показывает сборку. В локфайле Vite 8.3.8, GSAP 3.15.1 и Lenis 1.3.27. Стартовый проект проверен на Node 22.21.0.
- `vite.config.js` задаёт `base: './'` и включает манифест. В `dist/.vite/manifest.json` вход `index.html` указывает на JS-модуль и CSS для подключения в шаблоне WordPress. Сохраняй относительные пути и ограничивай стили лендингом. Тему, шаблон, плагины и правила редактирования контента согласуем на этапе интеграции.
- По просьбе пользователя панель встроенного браузера скрыта. Для проверки оставляй её скрытой, если пользователь не попросит показать.

## Перед вёрсткой и публикацией

- Начинай с конкретного блока и подтягивай его фреймы всех трёх размеров и связанные варианты компонентов. При спорных состояниях сверь визуальный рендер и прототип. Картирование выше основано на дереве, стилях и текстах REST API.
- До наполнения утвердить полный перечень направлений, истории, показатели, ответы FAQ и финальную редакцию текста. В макете встречаются опечатки и расхождения между копиями.

- Проверять 375, 768 и 1440 px и промежуточные ширины: переносы и кадрирование, меню, CTA и формы, аккордеоны, настройки cookie, клавиатуру и режим уменьшенного движения. Перед переносом собрать проект и сверить манифест.
